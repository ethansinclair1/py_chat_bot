# PyPal

A chat app for Python questions, built with React and TypeScript.

It works out of the box with built-in answers for common Python topics. Add an Anthropic API key in Settings to get full answers from Claude. The key is stored in your browser only.

## Features

- Chat interface with code blocks and copy buttons
- Offline mode with answers on lists, dicts, loops, functions, classes, files and more
- Optional Claude integration using your own API key
- Light and dark theme

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deployed to GitHub Pages on every push to `main`.
